# Automation Testing Project

This repository is the central hub for my automation testing project.

The project brings together UI test automation frameworks built for the same application using different programming languages and ecosystems. 

The main goal is to demonstrate practical automation testing skills, software engineering practices, and continuous professional growth.

#### The application under test (AUT) is: https://the-internet.herokuapp.com/


## Purpose
- Showcase practical QA automation skills via this project.
- Compare automation approaches across multiple programming languages.
- Demonstrate test design, framework architecture, Git workflow, CI\CD, and project management.
- Expand the project incrementally with new features and test coverage.
